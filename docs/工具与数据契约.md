# 工具与数据契约

本文维护工具职责、数值保护和证据边界；当前安装/尺寸及实测进展见 [README](../README.md)，计划字段、CLI 和审核协议统一见[计划指南](../.agents/skills/embodied-agent/references/plan-format.md)。工具已实现不等于所有场景均已验收。

## 适配与工具

策略由 agent 组织，执行器校验并推进阶段，工具封装可复用设备能力。场景识别/几何在任务代码中完成，不注册任意 Python 执行工具。换设备时提供工具实现、能力清单、现场配置；[适配器入口](../scripts/adapters/__init__.py)负责注册，核心无需按设备分支。

`ToolRegistry.invoke(name, args)` 校验输入、调用已注册函数、校验输出。[能力清单](../config/capabilities/)给出精确 Schema；execution_mode 的 compute/read/control 分别指本地计算、设备读取、物理控制，不额外触发授权流程，范围由 prompt 决定。xMate 能力版本 11，当前 8 项工具：

| 工具 | 输入与边界 |
| --- | --- |
| observe | sources 为 rgb/gripper，可传本机 web_url 和单调时钟 after；复用常驻传感器，保存原图/反馈，不定位、不连接设备、不切换所有者 |
| robot_state | 参数可为 `{}`；取得 Web 租约，要求网页机械臂断开、实机空闲；独立 SDK 子进程读取后断开，values 保留 SDK 字段名，完整查询在 log_path |
| move_gripper | target_position 为 0..1000，单次变化最多500，力按 control.yaml；调用方确认支撑、释放方向和外廓，不自动等同于安全释放 |
| close_gripper | target_position 为 0..999；要求初始化完成、状态1、位置1000的全开空夹起点，力按 control.yaml闭合至稳定接触；不接近、不抬升 |
| plan_joint_route | path_spec 指向本轮 TCP 路径文件；实读起点/工具，连续 IK/FK、整理及检查，返回 checked_route_path；不运动、不识别障碍 |
| plan_joint_routes | batch_spec 指向候选/阶段文件；一次会话返回各阶段可执行的检查结果 routes，首段实读、后段从预测终点求解；不运动 |
| check_joint_route | route_path 指向显式关节路线；实读限位并采样 FK，返回 checked_route_path；不产生路线、不运动、不判定碰撞 |
| execute_joint_route | 消费 checked_route_path 一次，核对原记录及实际起点/工具/负载/参考系/限位，复用 FK 采样，执行后下电断开；不控制夹爪或拍照 |

观测返回 origin=live、collected_at、所选 rgb.image_path/metadata_path/metadata 和 gripper 采样包。collected_at 是调用完成时间，各源并不同步；使用原包的采样时间和帧号。常驻服务及所选传感器须已连接；失败不自动直连或重连。新帧、采样年龄和租约的具体约束统一见 [Web 常驻接入](Web控制台.md#任务脚本接入)。历史报警不当作当前故障，单样本 stable 不证明持续稳定抓持。

## 夹爪与携物

位置是寄存器单位，不是毫米；力百分比不是力传感器读数。USB 在线也不证明夹爪独立电源已通电。协议入口：

| 寄存器 | 含义 |
| --- | --- |
| 读 0x0200 | 初始化状态：0未初始化、1完成、2进行中 |
| 读 0x0201 | 夹持状态：0运动、1到位无物、2接触、3掉落 |
| 读 0x0202 | 实测位置 |
| 写 0x0101 / 0x0103 | 力20..100% / 位置0闭合到1000全开；当前工具从 control.yaml 读取 |
| 写 0x0100 | 初始化/回零；不自动写入 |

闭合只写一次目标，约150ms轮询、15秒超时、接触后5次稳定确认；到终点无接触、接触丢失、位移异常或初始化异常均报错，不重发。grasp_close CLI 默认终点0，指定范围0..999；复用常驻连接需 --resident，运动需 --execute。到位必须同时检查状态、误差及稳定窗口，不能仅等状态非零。释放需验证支撑、目标大于当前开口、张开到位及外廓，狭窄盒内不能自动全开。

### 携物反馈

每段抬升/携物显式绑定 execute_joint_route.holding_position 到本轮 close_gripper.actual。工具在动作前后各取调用后新鲜的5个样本，要求已连接、初始化完成、状态2，距闭合位置最多3单位、窗口位置极差最多2单位；运动中约每150ms检查新鲜接触/位置，传输与轮询另增延迟，不是硬实时保护。丢失、漂移、断连或过期使动作异常并停止/下电；成功返回 holding_verified=true 及 gripper 包。

释放后不传 holding_position。未传参数时仍有已检测到夹持后的自动监测，但起步前已丢物可能不启用，不能代替显式预期。反馈不识别对象或测量抗滑力；身份/几何/场景存疑时看图，常规携物不强制中间视觉，最终放置仍看新图。动作异常可能触发现有控制器断连，应显式重连并读取状态后决定剩余工作，不重放结果不明命令。

## 关节路线工具

规划/检查/执行均须 manual、idle 和独占权，不要求预先下电。规划/检查不切电源；执行已上电则使用，否则上电确认后再提交队列。不得自动切模式、清报警或回零。SDK/视觉进程隔离与安装值见 README。

| 路线字段 | 格式与单位 |
| --- | --- |
| start_joints_deg | 六个实际起始关节角，度；执行起点容差0.03° |
| waypoints_deg | 1..100个六轴目标，度；无固定单段变化角度上下限，仍须检查实际限位/路径 |
| tcp_bounds_m | `[[xmin,xmax],[ymin,ymax],[zmin,zmax]]`，SDK endInRef，米；本轮显式给出 |
| rate | 0.01..1.0，关节速率比例，不超过本轮授权 |
| blend_radius_mm | 可选；原始关节文件默认0，新规划路线默认1；0为逐点停稳，非零仅1..5mm，最后一点总是0 |

先检查，再消费 checked_route_path；route/context/segments 摘要须与原检查日志匹配。实际起点、工具、负载、参考系、限位及 TCP/FK 重核通过才复用采样。没有摘要的旧检查不能补凭证；场景变化须重新规划。执行前排他写 `logs/runs/joint-route-<内容摘要>.attempt.json`，改名、改 run_id 或删除标记都不使已尝试路线可重放。

### 规划与采样

path_spec 文件必需 tcp_matrices_row_major、tcp_bounds_m；rate 省略时读取 [control.yaml](../config/control.yaml)，也可选 blend_radius_mm 及 keypoint_indices。已检查路线固定预检时的 rate，配置修改不改写它。矩阵为行优先4×4，关键点下标递增、零起始且包含末点。SDK-free 采样函数及批量文件样例见[计划指南](../.agents/skills/embodied-agent/references/plan-format.md#batch-paths)。

连续 IK 传播上一解构型，FK 回算后合并近共线关节采样（偏差最多0.01°），保留关键点，再检查关节插值路径；关键点保留不代表中间必须停稳。超100路点、限位或 TCP 范围不合格则拒绝。相邻 IK 解超过10°不单独拒绝，max_joint_step_deg 仅作诊断；通用 IK error 不能直接归因为限位或奇异。SDK 矩阵先用 utility.transArrayToPosture 转姿态再构造 CartesianPosition；confData 从实际 FK/连续解传播，不假定二值构型，此机型不能依赖 calcAllIkSolutions。

FK 检查最大单轴间隔1°并保留段端点，限位余量至少0.5°、abs(J5)>=5°，TCP 在任务范围内。控制器软限位曾读为disabled，仍使用实读限位检查；当前安装参考值 J1±165°、J2±115°、J3[-165°,140°]、J4±115°、J5±165°、J6±115°。J5条件不是完整奇异检测，采样不保证点间空间偏差，IK/FK不提供整臂碰撞保证。

批量候选共用同一会话/配置的 FK 缓存；几何拒绝可尝试下一候选，设备/控制权错误停止。各阶段分别保存检查结果，每段末点精确停稳，夹爪动作和审核位于阶段之间。不要预检全路线后又逐段重新规划；仅未来几何真正未知时分次规划。目的地/通行姿态应在抓取前确认可达，生成目标文件不等于通过检查。

诊断日志：planning_input/planning_result 保留矩阵、已解样本、失败点前解/构型/错误；candidate_cost 记录 IK 耗时及关节行程，phase_checked 记录 sample_rows/fk_calls/fk_cache_hits/fk_elapsed_s/elapsed_s。fk_elapsed_s 仅累积采样循环 SDK 调用墙钟时间，不含额外上下文核对，也不能分辨 SDK 算法与通信。

### 速率与过渡

原生 jointSpeed=rate，speed=-1 为默认哨兵；执行检查原生可写属性并读回比例。非实时模式/moveReset 后、上电/入队前显式 adjustSpeedOnline(1.0)，成功才记录 speed_configured 的 joint_rate、online_scale、waypoint_zones_mm、SDK路径。在线倍率跨会话保留，结束保留1、每次重设；无读回接口，日志仅证明 SDK 成功应答。接口缺失或失败走原停止/下电流程，不发送上电或队列命令、不回退。实测效果见 README，旧 worker 不会热更新。

整条队列一次入队/启动，按控制器路径ID、路点索引及到位事件监测；终点再取5次稳定反馈。过渡参数与检查摘要/尝试标记绑定，不能事后修改。SDK小于1mm的zone属于fine，故拒绝0..1的小数。过渡时 setAutoIgnoreZone(False)，收尾恢复True；FK样点距TCP范围边界至少留出过渡半径。

运行中反馈偏差检查使用0.1°关节插值，不调用FK；允许相邻过渡段的0.5°路径邻域并保持实际限位/TCP范围。它不是控制器圆滑轨迹的完整仿真，也不证明整臂、夹指、物体和线缆无碰撞。MoveAbsJ不保证笛卡尔直线，狭窄路径可选0过渡并按场景留量。

### 监测与收尾

SDK worker 持有 sdk_runtime 独占锁和 Web 租约，监测模式、电源、关节限位/路线偏差、TCP范围、携物反馈，每路点90秒超时。结束或异常执行 stop → 等待idle → 下电 → 断开；无法确认记 cleanup_unconfirmed，不能当已停止。任务期间从该 SDK 所有者获取状态，不另开查询连接。

调用进程转发 INT/TERM/HUP 并等待收尾，worker 检测父进程消失；不使用 SIGKILL。SDK阻塞/进程强杀等情况下软件不能保证停止，须用设备停止手段。worker_started含PID，stop_requested/powered_off/disconnected为收尾证据。Web的Hardware.safe_stop没有完整idle等待，不能直接代替任务级停止验收。异常不自动松爪；关串口不会取消夹爪动作，机械臂下电不会释放物体。

## 场景算法与证据

定位使用当前标定及已知高度，工具反馈不补齐对象身份、碰撞、毫米开度、六维姿态或全程朝向。block_top只拟合红色矩形顶面，不能用整体色块中心替代；CLI必须给 --image、--output、--session、--size-mm 长 宽、--top-height-mm、--roi x y width height，输出目录须不存在，失败不回退。现有误差/边缘阈值并非任意对象精度承诺。

placement_rgb的rim_candidates需两张真实图和已知盒沿高度；plane_points可对单帧指定像素求交。旧放置输出 floor_height_mm_user_provided=0 是写死值，不能当新测量或用户新提供的盒底高度。直连capture只保存JPEG且无常驻硬件帧元数据，不能伪装成常驻新帧包。坐标/平面规则见 README，安装变更见[标定](标定.md)。

| 来源 / 字段 | 证据能说明什么 |
| --- | --- |
| GripperMonitor.snapshot：state.initialized/status/position、samples/stable/age_seconds | 新鲜多样本状态/位置稳定；单样本stable不等于持续夹持 |
| close_until_contact：start/target/actual/force_percent/holding | 闭合稳定接触，不证明对象身份或可靠随动 |
| Hardware.gripper_step：start/actual/force_percent/holding | 开合结果；已到位分支只有actual/already_at_target，缺字段不补值 |
| 相机包：received_monotonic、frame.frame_number/timestamp_ms/clock_domain/host_received_utc | 帧号、采样时钟和年龄；不能只按文件修改时间判断新鲜 |
| SDK状态：joints_deg/tcp_m_rad/flange_m_rad/mode/power/operation及原查询字段 | 实读姿态/状态；带错误的值不是成功样本 |
| IK paths[].complete/failure/max_joint_step_deg/min_abs_j5_deg | 采样运动学结果，不是无碰撞许可 |

数值/枚举/布尔条件用local，身份和图像效果用model，混合要求拆开。工具未产生的字段保持unknown，expected文字不创造证据；模型不能覆盖保护失败。计划的completed只说明声明检查通过，agent仍负责覆盖原始目标。

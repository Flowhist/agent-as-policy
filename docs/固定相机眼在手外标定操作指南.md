# 固定相机眼在手外标定操作指南

日期：2026-09-29。适用设备：固定安装的 RealSense D455、珞石 SR4-C、自制夹指。任务控制 TCP 沿用现有 tool2（法兰 Z 偏移 248 mm、旋转为零）。

本指南是现场操作与验收流程，不表示标定已完成。当前项目已有拍照、机器人状态读取和小幅关节点动脚本，尚无配对标定采集、外参求解或自动标定运动程序。不要把一组散乱照片当作完整标定数据，也不要直接启动旧工程的任务或标定程序。

## 1. 目标与结果

目标是求出固定相机相对机械臂基坐标系的位置和旋转，使相机中的三维点能转换为机器人基坐标中的三维点。不需要人工测出相机在房间里的绝对坐标，也不需要目测底座正方向。

标定板刚性安装在末端，机器人带着板改变位置和朝向。每个姿态同时取得相机图像和机器人实际位姿。板相对末端的安装关系可以一并求解，不要求先用尺子精确测出安装偏移。

预期输出：相机到基座的外参、板到末端的固定变换、采集原始记录、误差报告和独立验证结果。它不自动验证 tool2 的真实抓取中心，不自动获得桌面高度、障碍边界或所有物体的三维位置。

## 2. 准备物品

| 物品 | 要求 |
| --- | --- |
| 标定板 | 推荐 ChArUco；棋盘格也可。必须有确切图案定义与实际尺寸 |
| 板材 | 平整、刚性、不反光；不要悬挂一张会弯曲的纸 |
| 安装件 | 支架、夹具或可靠固定件，使板与法兰之间在采集期间保持刚性 |
| 尺具 | 游标卡尺或可靠直尺，测量实际打印尺寸 |
| 现场控制 | 示教器及可立即停止机器人运动的现场操作条件 |

板尺寸先以相机实际可见性决定：可从约 A4 大小评估，但不要为填满画面安装过大、妨碍运动的板。距离较远时优先增大可辨识特征，不能只增加更多、更小的格子。

制作与记录标准：

1. 打印使用实际大小/100%，关闭“适应页面”；贴好后再测量。
2. 记录格子实际边长，建议横纵方向各跨多个格子测总长后除以格数，检查是否存在非等比缩放。
3. ChArUco 记录方格行列数、方格边长、标记边长、字典、生成软件及版本；棋盘格记录内角点行列数与方格边长。不要把方格数当成内角点数。
4. 保留原始图案文件。尺寸统一记录为 mm，软件转换为 m；尺寸不准确会影响标定尺度。

## 3. 固定设备并预览

1. 锁紧相机与支架，整理线缆，避免相机受拉动。记录相机序列号 `141322252639` 和安装照片。
2. 使用 D455 RGB 原生 1280×720、10 FPS。相机内参必须对应这个实际流配置；不能沿用旧 640×480 的数值或旧工程另一台相机的参数。
3. 安装标定板，尽量朝向相机。优先固定在刚性支架上；若夹爪夹持板，采集期间不得开合，且必须确认不会滑移。
4. 板不能遮挡需要观察的运动区域，不能碰到夹指、台面、机器人或线缆。新增板和支架的质量/重心对负载设置的影响需要核对，不能假定仍等于原负载。
5. 用当前拍照命令检查视野：

```bash
python3 /home/embotic/agent-as-policy/scripts/capture.py
```

照片在 `/home/embotic/agent-as-policy/captures/`。该命令只拍图，不采集机器人位姿，不能单独完成手眼标定。

图像要求：板在原始分辨率下有足够像素，角点清晰，黑白边界不糊、不反光、不大面积过曝。优先让完整板入镜并留边缘余量。正式采集程序应显示角点检测结果；肉眼觉得清晰不等于算法已经可靠检测。

自动曝光可以用于标定，关键是停稳后画面清晰。正式采集持续保持相机运行，先预热至亮度稳定；无需每个姿态重新启动相机。

## 4. 采集软件须先具备的能力

开始正式采集前，应实现一个“采集当前姿态”的命令，完成下列配对记录，而不是让操作者手动匹配图片时间和日志：

| 每个样本必须保存 | 内容 |
| --- | --- |
| 样本编号与图像 | 原始分辨率、优先无损 PNG；保存成功后才计入样本 |
| 时间 | 主机时间、相机帧时间戳及其时钟域、机器人读数时间/读取区间 |
| 机器人状态 | 实际六轴关节、法兰相对基座位姿、运行模式及运动状态 |
| 前后位姿 | 拍照前后各读一次实际位姿，确认曝光期间末端静止 |
| 相机参数 | 序列号、RGB 分辨率/FPS、对应内参、畸变模型与系数 |
| 标定板定义 | 图案、尺寸、字典等，以及本轮固定安装的标识 |
| 检测结果 | 已识别角点/标记 ID、像素坐标和质量判定 |

推荐使用 SDK 的 `flangeInBase` 实际位姿求解，降低工具/工件坐标设置混淆；任务执行仍使用 tool2。若改用 TCP 位姿，必须在整套求解中一致使用同一个已定义参考系，不能混用。

机械臂 SDK 连接应由单一程序持有。SDK 连接/断开可能影响运动；不要在示教器或其他程序正在运动时反复运行 `check_connection.py`，也不要让两个控制程序同时操作机器人。

相机时间戳不一定是主机 UTC。停稳采集可降低同步要求，但仍需记录时钟域，并用曝光前后的机器人实际读数验证稳定，不能只按“请求拍照”的时刻匹配。

## 5. 现场采集步骤

首次采用现场人员控制姿态、软件只采集的方式。现有 `jog_once.py` 用于微小关节验证，不应直接拿来拼接大范围标定轨迹。自动运动采集需另外实现并验证。

1. 在板清晰可见且周围有余量的位置建立起始姿态，确认没有其他任务控制机器人。
2. 停止运动，通常等待约 0.5～1 秒消除振动，再由采集程序确认位姿稳定。
3. 采集一组图像与实际位姿。检查角点覆盖、清晰度和配对记录；不合格样本保留失败原因但不加入求解。
4. 以低速移动到下一个经过现场检查的姿态。动作幅度由实际可用空间决定，不照抄固定坐标或角度。
5. 重复取得约 15～25 组有效求解样本，再另采至少 5 组独立验证样本。数量是建议，不是充分条件，姿态多样性更重要。

姿态分布要求：

- 板覆盖画面左、中、右及不同高度，且有一定距离变化，尽量覆盖实际任务使用区域。
- 有绕至少两个不平行方向的明显倾斜变化；在可行范围内，部分姿态差异可达约 10～30 度，但这只是几何采样建议，不是可直接执行的运动命令。
- 避免全部只有平移、全部平行于相机、只绕同一根轴旋转或采很多几乎相同的姿态。
- 不能为了增加变化把板转成侧面、移出视野或进入碰撞风险区域。变化不足时应调整板的安装方案，而不是硬凑样本数。
- 采集中相机、板安装或机器人底座有任何松动/移动，停止并重新建立该轮数据，不混用前后样本。

## 6. 外参计算约定

本节用于后续实现与结果检查，现场操作者无需手工计算矩阵。

约定 `T_A_B` 把 B 坐标系中的点转换为 A 坐标系。每个样本满足：

```text
T_base_camera * T_camera_board(i)
    = T_base_flange(i) * T_flange_board
```

已知：图像与相机内参得到的 `T_camera_board(i)`，以及机器人实际反馈 `T_base_flange(i)`。待求：固定的 `T_base_camera` 和 `T_flange_board`。结果保存方向必须明确，并核验变换与逆变换，不可只写一个含义不明的“外参矩阵”。

使用成熟的 OpenCV 标定/PnP 与手眼或机器人-世界联合标定实现，按其 API 的变换方向转换输入；不能直接照搬眼在手上示例的矩阵顺序。所有机器人欧拉角转换需遵循 SDK 约定，并用已知姿态验证。

RealSense 的畸变模型需要明确适配：此前读取曾返回 `inverse_brown_conrady`。不能因系数数量相同就原样当作 OpenCV 普通 Brown-Conrady 畸变参数使用。应采用经验证的去畸变/投影转换路径或另行标定适配的 RGB 内参，并保证输入图像与使用的内参一致。

## 7. 验收标准

先看数值一致性，再做独立几何验证，最后才用机器人接近物体。以下数值是本项目的初期目标，不是已经达到的精度或厂家保证。

| 检查项 | 初期目标 / 判定方式 |
| --- | --- |
| 角点重投影误差 | 以原始 1280×720 像素统计；RMS 争取低于 1 px，并检查明显离群样本及误差分布 |
| 固定安装一致性 | 各样本反算的板到法兰变换应一致；同时报告平移残差 mm 与旋转残差 deg |
| 独立验证 | 至少 5 个未参与拟合的姿态；机器人侧与视觉侧推算的板特征位置应一致，记录均值与最大误差 |
| 位置误差预算 | 初期争取独立验证最大误差在 3～5 mm 内；是否够用由物体尺寸、夹指间隙与边界余量决定，精密任务需更严 |
| 物理检查 | 先在目标上方保留充足高度进行对照，不直接触碰板或台面；实际误差需独立测量，单凭“看起来对齐”不能验收 |

独立姿态仍共享同一块板和机器人反馈，无法充分发现所有系统误差。必要时用独立已知长度/位置做交叉验证。不要用参与拟合的样本误差很小来宣称抓取精度达标。

误差不合格时，优先检查实际板尺寸、角点质量、板滑动、畸变模型、姿态多样性、时间配对和变换方向。不要仅通过删除所有不利样本来获得低误差。

## 8. 标定完成后：桌面与任务空间

1. 相机外参通过验证后，可将标定板从末端拆下，平放到实际操作表面；拆板不改变已求出的相机到基座外参，但原板到法兰变换不再适用于新的安装。
2. 通过图像估计板在基座下的位姿。结合板厚及其图案面到支撑面的距离求出桌面平面；台面不一定与基座 XY 平面平行，不能只存一个未经验证的 Z 高度。
3. 分别测取物面、放置面、盒底及盒沿。现场白纸应平整固定，不能把翘曲纸张当作稳定基准；金属底板和黑色平台也应分别处理。
4. 定义允许的任务区域和障碍，结合夹爪整体几何、工具长度与误差预算设置余量。
5. 单张 RGB 图像中的像素即使有外参也只确定一条空间射线。定位三维点还需要已知平面/物体高度，或经过对齐与验证的深度数据。D455 深度用于定位时应记录为深度增强版本。
6. 核实物体尺寸与夹指间距。tool2 按现有参数使用，但实际抓取偏差仍需要受限试验验证；外参正确不等于抓取 TCP 一定准确。

## 9. 何时需要重新标定

- 相机或其支架相对机器人底座移动：重新标定外参。
- 机器人底座相对相机移动：重新标定外参。
- 只移动标定板：已完成并验证的相机到基座外参仍可保留；重新做手眼采集时重新建立板的固定安装关系。
- 更换夹指或 tool2：核实 TCP/负载/几何；若相机与底座都没动，不必因此一律重做相机外参。
- 改变分辨率、裁剪或图像处理方式：使用对应内参与正确像素映射，重新验证投影；不能直接复用旧像素参数。
- 移动桌面、托盘或目标区域：重新定位对应任务平面/区域。

## 10. 当前最短执行清单

1. 准备标定板，提供图案定义、实测尺寸和安装方式。
2. 固定到末端，用现有拍照命令确认清晰可见。
3. 实现并验证图像与机器人实际位姿的配对采集程序。
4. 现场低速调整姿态，采集有效样本及独立验证样本。
5. 求解外参并按误差预算验收。
6. 定位实际取放平面，验证受限 TCP 小步运动，再进入模型空跑与单步闭环。

# 固定 D455 标定与采集

本项目已有网页配对采集和离线求解。当前安装的结果见 [成功记录与标定快照](records/2026-10-06/README.md)，操作流程如下；新安装不要直接沿用旧外参。

## 准备与采样

固定相机与机器人基座，将平整、刚性的 ChArUco 板可靠固定到末端，采样期间不得滑移或开合夹爪。核对支架/板的负载与运动空间。当前板是 12×9 格、方格 15 mm、标记 11.25 mm、ID 0–53；软件用 OpenCV 5×5/1000 字典超集检测，不据此推断厂家完整字典名称。更换板先更新定义并实测打印尺寸。

使用 D455 serial `141322252639`，RGB 1280×720 / 10 Hz，内参与实际流一致。图像须清晰、不过曝、有足够角点，不能只凭肉眼认定检测有效。

1. 网页取得控制权、连接机器人、开启相机预览；现场低速调整到经过检查的姿态。
2. 退出拖动，停稳约 1 秒，点击 **采集标定样本**。采集期间禁止运动、重复点击和开合夹爪。
3. 检查成功/失败提示与角点覆盖，再调整下一姿态。保持控制网页可见并发送心跳。
4. 建议约 20 组求解、至少 5 组独立验证，覆盖不同位置、距离及至少两个不平行方向的倾斜。不要以重复姿态凑数量。

终端也可复用网页连接采样：

```bash
python3 scripts/calibration_capture.py --session captures/calibration/session-new
python3 scripts/calibration_capture.py --session captures/calibration/session-new --split validation
```

默认前 20 条标为 train，之后为 validation；也可显式 `--split train`。本次已完成实验实际使用 15+5 划分，不能把默认标签当成实际求解划分。安装变化后必须新目录。

仅不使用网页时才用 `--direct`，先断开网页机器人并关闭预览。网页采集失败不会自动切换独占模式，不要强杀进程抢 SDK 锁。采集不发送运动、上电、夹爪或模式切换指令；SDK 与视觉在独立进程。

## 记录与求解

目录内保存 `samples.yaml`、原始无损 PNG、`-corners.png` 角点预览和采集诊断。有效样本包括内参/畸变、板定义、角点、帧时间及其时钟域、四次实际机器人读数、SDK 转换的行优先法兰矩阵和稳定性结果。

采集要求至少 20 角点、覆盖宽度 75 mm/高度 60 mm；相对首读的关节变化不超过 0.01°、法兰平移不超过 0.2 mm。这只是采集过滤，停稳配对也不等于硬件同步。失败不加入 YAML，中断留下的未引用图片不自动成为样本。

```bash
# 只检查图像，不访问设备。
python3 scripts/calibration_capture.py --check-image /absolute/path/to/image.jpg
# 查看求解入口；核对当前脚本的划分规则与输出位置再运行。
python3 scripts/calibration_solve.py --help
```

变换约定：`T_A_B` 把 B 坐标转换到 A。求解满足：

```text
T_base_camera * T_camera_board(i) = T_base_flange(i) * T_flange_board
```

使用实际 `flangeInBase`，不与任务 TCP 混用。RealSense `inverse_brown_conrady` 须按官方射线去畸变，不能直接当普通 OpenCV Brown 系数。距离统一米、角度注明单位。

## 验收与平面

检查原图重投影误差、每组板到法兰一致性及独立验证的平移/旋转均值和最大值。初期可争取重投影 RMS <1 px、独立位置最大误差 3～5 mm，但实际门槛由抓取间隙和障碍留量决定，不是厂家精度保证。拟合误差低不等于实物准确；先在目标上方核对，必要时用独立尺寸验证。误差异常检查板尺寸/滑动、角点质量、姿态多样性、时序和变换方向。

外参通过后，用板在桌面的图像及图案面到桌面的实测高度求桌面平面（`table_plane.py --help`），分别确定物体顶面、盒底、盒沿和其他支撑面。RGB 像素只确定射线，需要已知平面/高度或经验证的深度才能定位。外参正确不自动验证工具接触点。

相机/基座移动需重新标定外参；只更换夹指需复核 TCP、负载与外廓；只移桌面/托盘需重新定位对应平面/区域；分辨率或裁剪改变需适配内参与像素坐标并重新验证。采集中板相对法兰变化则重新建立采样会话。

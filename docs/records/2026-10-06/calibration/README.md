# 安装标定快照

从实验主机 `captures/calibration/session-01/` 原样复制，2026-10-06 整理入库：

- `samples.yaml`：相机内参与 20 组配对检测/机器人姿态；保留采集时的原路径和时区。
- `solve-15-validate-5/result.yaml`：前 15 组拟合，后 5 组独立验证的结果。
- `table-plane.yaml`：暂定桌面平面，标定板图案面离桌 503.25 mm。

这些数据属于固定 D455 serial `141322252639`、RGB 1280×720、当时的相机/机器人/桌面安装。它们不会自动影响任何脚本，运行仍读取本机 `captures/calibration/session-01/`。

仅在安装及成像配置未变化并复核通过时，将本目录的三个 YAML 文件按相同相对路径恢复到本机工作目录。目录内 README 不需要复制。相机、基座或桌面改变后应重新标定，不要直接恢复旧快照。原始图像不在此快照中；需要重做图像检测时另行迁移原始 `captures/`。

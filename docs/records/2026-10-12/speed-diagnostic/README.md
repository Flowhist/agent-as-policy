# J6 速度倍率实机对照

2026-10-12 17:07-17:14，Asia/Hong_Kong。用户允许任意关节在当前情况下 20 度以内进行快速实机诊断。本轮 J6 在约 -99.29485 到 -87.29485 度之间运动，单次约 12 度，空夹位置 480，manual，指令速率始终 0.1。

## 结论

本轮复现的 MoveAbsJ 约 1.08 度/秒慢速来自额外生效的非实时在线速度倍率。保持 jointSpeed=0.1、路线、工具和加速度设置不变，只调整 adjustSpeedOnline，即可将速度按比例改变；设为 1 后单段与 12 段均约 7.2 度/秒，与 Jog 相近。最后设为 0.15 又复现原来的 1.08 度/秒。

原倍率没有读取接口，不能声称直接读到了 0.15；这是由干预、比例响应和复现确定的等效值。是谁、何时设置了原倍率仍未知。本轮确认设为 1 后跨 SDK 断开/重连仍保留，不是每次连接自动恢复为慢速。生产路线只设置 jointSpeed，未显式管理这项独立倍率，因此受既有控制器状态影响。

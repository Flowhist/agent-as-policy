## 通信与协议

- 配置来源：`/home/embotic/myDCCS/DCCS/src/components/tool/dhrobotics/launch/dhrobotics.launch.py`。
- 驱动来源：`/home/embotic/myDCCS/DCCS/src/site-packages/omnilibs/driver/EOAT/modules/DHAG485/`。
- 当前 USB 序列号 AQ0296VS 与 launch 配置一致，稳定路径为 `/dev/serial/by-id/usb-FTDI_FT232R_USB_UART_AQ0296VS-if00-port0`。
- Modbus RTU，9600 baud，8N1，从站 2。注释中的旧配置为另一个 USB 序列号、115200 baud、从站 1。
- 读保持寄存器：0x0200 初始化状态（0 未初始化、1 完成、2 进行中）；0x0201 夹持状态（0 运动、1 到位无物、2 夹持、3 掉落）；0x0202 实测位置。
- 写寄存器：0x0100 初始化（1 单向回零、0xA5 完整标定）；0x0101 力百分比（20~100）；0x0103 位置（0~1000，0 闭合、1000 张开）。ROS 接口位置为 0~100%，与硬件层相差 10 倍。
- 所读驱动未提供速度与独立停止接口；断开串口不代表夹爪停止或断电。实际指尖间距与位置寄存器的对应关系待测，不能直接把百分比当毫米。

## 后续小幅验证

先取得有效且稳定的初始化/夹持/位置反馈。未初始化时，回零可能需要大行程，不能作为小幅测试自动执行。已初始化且空载静止时，可先以最低支持力设置尝试当前位置附近 10 个原始单位（全行程 1%）的动作，结合连续位置反馈和前后图像确认方向与到位；没有应答、夹持或掉落异常时停止后续指令，不自动重发或回位。

旧 ROS 封装存在到位判据局限：写位置后只等待状态不为 0，可能读到上一动作的停止状态，且状态 2/3 也会退出等待。后续执行层应同时核对目标误差、状态和连续位置稳定性。反馈“夹持”也不能代替图像对实际抓取成功的验证。

旧机械臂组件使用 C++ SDK 0.7.2，其状态话题 position 是 flangeInBase，不能直接当作当前项目的工具 TCP。当前项目继续使用已经验证的 Python SDK 0.7.1。旧相机的外参和旧料架坐标不能未经验证移植到 D455。

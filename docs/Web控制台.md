# 局域网关节与夹爪控制台

2026-10-06 隔离保护更新：相机继续在 spawn 子进程运行，标定视觉处理通过独立解释器执行。共享 SDK 入口现在主动拒绝与 OpenCV/RealSense 同进程加载，两种导入顺序均受保护；断开 SDK 不解除此限制。

## 启动

在 Ubuntu 项目根目录运行，使用系统 Python 3.10（已有 pymodbus 3.14、pyserial、RealSense 与 OpenCV）：

```bash
python3 scripts/web_control.py
```

默认监听 `0.0.0.0:8080`。本机访问 `http://127.0.0.1:8080`；同一局域网设备访问 `http://192.168.0.10:8080`。无需访问码或登录，浏览器自动建立用于区分控制端的会话。端口被占用时用 `--port 8082` 等指定空闲端口。

页面、脚本和图标均在本地提供，无需客户端访问外网。只用于可信局域网；HTTP 不加密，不对公网转发该端口。

已安装用户级服务 `agent-policy-web`，非登录/开机自启。进程异常退出后 2 秒重启，60 秒内最多启动 5 次；重启后设备保持未连接，控制权清空，不恢复动作。查看、启动或停止当前后台实例：

```bash
systemctl --user status agent-policy-web
systemctl --user start agent-policy-web
systemctl --user stop agent-policy-web
journalctl --user -u agent-policy-web -n 50 --no-pager
```

服务定义保存在 `config/agent-policy-web.service`，安装位置为 `~/.config/systemd/user/agent-policy-web.service`。当前服务日志写入 journal；旧临时实例日志保留在 `logs/web-server.log`。停止后台实例后可使用上面的 Python 命令在终端重新启动；不要同时启动两个实例。

## 操作流程

1. 直接打开网页。
2. 单击取得控制权，无确认弹窗。一次只有一个浏览器可控制，其他设备可查看状态及请求停止。
3. 分别连接机械臂、夹爪。启动服务、打开页面不会自动连接硬件或运动；机器人 SDK 连接本身可能重置运动，不能在其他任务执行时连接。
4. 拖动各关节滑条设置绝对目标角度，也可在数值框精确输入，再点击该行“应用”。拖动和输入不会发送运动指令，状态刷新保留未应用目标。默认 SDK 速率 1%，可选至 10%；滑条范围为当前角度 ±50 度与 SDK 关节范围的交集，精度 0.1 度。执行前后端重新读取实际角度，核对单次变化不超过 50 度及目标处于 SDK 范围内；超时按行程和速率计算（50 度、1% 速率为 210 秒）。只接受手动、空闲及正常电源状态，不自动切换模式。运动完成后停止并下电。
5. 夹爪滑条和数值框设置目标开度百分比（0% 闭合，100% 张开），点击其“应用”执行，固定力设置 20%。滑条范围为当前开度 ±50% 与 0～100% 的交集；后端根据实际反馈重新校验单次行程。要求已初始化、到位未夹持。不自动回零；目标超出 0～1000 时禁止执行，不静默截断目标。到位等待上限 15 秒。
6. 开启拖动示教后，使用机械臂实体末端按钮拖动。代码调用 `enableDrag(0, 2, ec, False)`，保留实体按钮条件，采用关节空间自由拖动。开关根据实际 SDK operationState 显示；不支持或条件不符时显示错误，不绕过控制器要求。
7. 拖动开启时禁止关节点动与夹爪操作。松开实体按钮、停稳后可命名并记录示教点；关闭示教将停止、退出拖动并下电。
8. 调整完成后释放控制权，或按“停止机械臂”；结束服务用 Ctrl+C。

网页大步长按用户要求扩大，原命令行小步脚本保持原限制。大角度范围已做软件校验与模拟测试，不代表大幅实机路径已经验证；仍需检查整段路径中的障碍、线缆及自碰撞。

## 相机与示教数据

### 配对标定采集更新

`python3 /home/embotic/agent-as-policy/scripts/calibration_capture.py` 默认通过网页服务的一键采样接口复用现有连接。保持预览开启、机械臂连接、网页控制权有效；退出拖动、停稳后运行。浏览器与终端并排显示，避免隐藏页面触发原有控制权释放。相机进程提供带内参/帧时间的原始 PNG，机器人线程串行读取前后法兰位姿；保存到 `captures/calibration/session-01/samples.yaml`，不采用下述普通示教点或 JPEG 预览替代标定样本。参见 [一键采集说明](标定一键采集.md)。

本机 `/api/calibration/capture` 接口不夺取浏览器控制权、不切换模式、不连接新设备；机器人必须已连接、空闲，预览已出图。采集期间拒绝其他动作，采集拒绝不自动断开设备。首次代码更新需在空闲时重启服务。

- 相机可单独开启预览，1280×720、10 Hz；曝光使用 `config/camera_rgb.json`，2026-10-06 为手动曝光 80、增益 64，自动曝光关闭；启动约 3 秒预热。RealSense/OpenCV 在独立 spawn 进程中加载，避免与机械臂 SDK 共处一个进程；子进程异常时页面报告相机错误。只显示最新图像，不积压视频。示教相机不自动随控制权释放关闭；停止预览或关闭服务后释放相机。
- 开启网页相机时，不要同时运行拍照脚本或其他相机程序；图像过期/设备异常时页面隐藏旧画面并显示状态。
- 示教点在 `logs/web/teaching-points.jsonl`，包含实际关节角、`endInRef` TCP 位姿、`flangeInBase` 法兰位姿、夹爪反馈、时间与名称。角度数组 `joints_deg` 为度，位姿 `_m_rad` 为米/弧度。
- 保存点位前多次读取关节，位置变化超过 0.01 度则拒绝保存。页面可导出全部点位 JSON。
- 本版不提供自动回到点位或轨迹回放。示教点没有配对同步标定图像，不能直接作为完整手眼标定样本。
- 操作和错误保存在 `logs/web/web-*.jsonl`。相机预览图像不自动落盘。

## 停止与连接边界

- 不排队执行动作。执行中提交第二个动作会被拒绝；拖动模式下也限制其他运动。
- 控制浏览器每秒发送一次心跳，5 秒未收到则撤销控制权并请求机械臂停止、退出拖动和下电。切换到后台或关闭页面会尝试主动释放控制权；若请求未送达，由心跳超时处理。恢复页面不会自动重获控制权或重发运动。
- “停止机械臂”是软件请求，不是硬件急停。SDK/网络调用阻塞、进程被强制终止、主机掉电时，无法保证停止延迟或清理完成；现场急停和人员监督仍必需。
- 夹爪协议没有已确认的独立停止指令。停止按钮阻止后续指令，但不能保证中断已发送的夹爪步进；关闭串口也不会给夹爪断电。
- 错误后撤销控制权、尝试停止下电并断开，不自动重连、回零、回位或重发。恢复需要重新取得控制权并连接。
- Linux 项目脚本共用 SDK 文件锁，网页连接机器人时，现有状态/点动脚本会拒绝再次占用 SDK。此锁不能约束旧 ROS 工程或其他外部控制程序，不要并行运行它们。
- 关节范围检查不能检测障碍、自碰撞、线缆或夹指；页面没有基于视觉的碰撞检测。

## 开发验证

完全不连接设备的模拟服务：

```bash
python3 scripts/web_control.py --simulate --host 127.0.0.1 --port 8081
python3 -m pytest -q tests/test_web_control.py
```

模拟模式在页面显著标注，模拟记录写入 `logs/web-simulation/`，不与实机示教点混合。模拟相机使用 captures 中已有图片，仅用于页面测试。

本次验证：17 项自动化测试通过，覆盖边界校验、单控制端、拒绝排队、停止取消、拖动失联退出、示教记录和 SDK 互斥。Playwright 完成桌面/手机模拟交互及截图检查，无页面脚本错误或横向溢出。实机网页已验证机器人与夹爪状态读取、D455 实时预览及设备断开；没有通过网页执行实机点动、夹爪动作或开启拖动，首次现场运动仍待验证。

后续更新：27 项自动化测试通过，新增相机子进程异常隔离、连接失败清理及大步长/超时校验。Playwright 模拟设备验证全部新关节档位、50 度动作、取消确认不执行、夹爪 50% 步进和越界按钮禁用，手机布局无横向溢出。新增大步长未由助手执行实机测试。

滑条更新：33 项自动化测试通过，覆盖绝对目标执行、参数校验及基于最新位置的行程限制。本次不执行实机运动测试。

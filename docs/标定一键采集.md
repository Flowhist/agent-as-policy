# 标定一键采集

推荐直接在网页相机预览下点击 **采集标定样本**。取得控制权、连接机械臂并开启相机预览后，调整姿态，退出拖动，停稳后点击。按钮下显示成功或失败原因，以及求解/验证样本数量；采集中禁止重复点击。无需运行终端命令，保持网页可见即可。保存目录与以下脚本一致。

默认通过本机 8080 端口的网页服务采集，复用网页持有的机器人和相机连接。每次手动调整姿态后，停稳约 1 秒，在网页退出拖动，保持机械臂连接和相机预览开启。保持夹爪夹持，不能开合。浏览器继续持有控制权和发送心跳；不要最小化或切换隐藏网页，可将终端与浏览器并排显示。

首次更新需要在机器人空闲时重启网页服务，使新采集接口生效；随后刷新页面、取得控制权、连接机器人并开启预览。脚本不会自行重启服务或抢夺控制权。

使用系统 Python（不是项目虚拟环境）运行：

```bash
python3 /home/embotic/agent-as-policy/scripts/calibration_capture.py
```

默认输出目录为 `/home/embotic/agent-as-policy/captures/calibration/session-01/`：

- `samples.yaml`：统一记录，每次成功采集原子更新，保留旧样本。
- 时间命名的 `.png`：原始 1280×720 RGB 无损图像。
- `-corners.png`：角点检测预览。
- `-capture.log`：网页采集的成功/失败诊断；`--direct` 模式使用 `-sdk.log`。

每条有效样本包含图像路径、相机内参/畸变模型、帧时间及其时钟域、板定义、标记与角点、四次机器人读数及读数区间、SDK 转换的行优先法兰到基座矩阵、稳定性结果。图像路径相对 YAML 所在目录。脚本只采集，不发送上电、运动、夹爪、模式切换指令；机器人 SDK 与相机/角点检测在独立进程中运行。网页机器人线程串行完成配对采集，期间拒绝运动命令，不重新连接设备。PNG 来自原始相机帧，不是网页 JPEG 截图。

前 20 条有效记录自动标为 `train`，之后为 `validation`。建议 20 组求解加 5 组独立验证；并非达到数量即可验收。覆盖不同位置、距离及至少两个不平行方向的倾斜，避免重复姿态或仅平移。验证集不参与拟合。也可用 `--split train` 或 `--split validation` 明确指定。

相机、底座或板相对法兰的安装发生变化后，必须用新目录：

```bash
python3 /home/embotic/agent-as-policy/scripts/calibration_capture.py --session /home/embotic/agent-as-policy/captures/calibration/session-02
```

程序不能自动发现安装滑动。不要为凑数量重复采同一姿态。采样成功后可直接在网页调整下个姿态。采样失败不自动断开网页连接；原有心跳丢失停止规则仍有效。不要通过强制结束占用进程来解除 SDK 锁。

仅当不使用网页时，才用 `--direct` 独占设备模式；该模式要求先断开网页机器人并关闭预览。默认网页模式失败时不会自动切换到独占模式。

当前板使用 12×9 格、15 mm 方格、11.25 mm 标记，ID 0–53。软件使用 OpenCV 5×5/1000 字典超集检测；不据此声称厂家完整字典名称为 1000。此前原图按该布局检出 87/88 个角点。每张至少要求 20 个角点且板坐标覆盖宽度 75 mm、高度 60 mm；这是采集过滤，不能代替最终重投影和独立精度验收。

程序预热约 3 秒，拍照前后多次查询，限制相对首读的关节变化不超过 0.01 度、法兰平移不超过 0.2 mm。停稳采样和清除排队帧降低时序误差，不等于硬件同步，也不能检测采样间发生又回到原位的运动。相机畸变按原模型记录，求解端还需正确处理 RealSense 的 inverse_brown_conrady。

失败不会计入 YAML；保存中断可能留下未引用的图像或日志，不会自动把它们加入有效样本。SDK 超时强制退出时会报告断开未经确认，需要现场检查。

离线验证已有图像（不连接设备）：

```bash
python3 /home/embotic/agent-as-policy/scripts/calibration_capture.py --check-image /absolute/path/to/image.jpg
python3 -m unittest discover -s /home/embotic/agent-as-policy/tests -p test_calibration_capture.py
```
